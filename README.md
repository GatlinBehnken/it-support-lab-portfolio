# IT Support Lab Portfolio

This portfolio documents selected hands-on labs completed through my MyComputerCareer IT training. The work focuses on practical entry-level support skills: Windows installation and administration, structured troubleshooting, networking, remote access, basic automation, and clear technical documentation.

> **Scope:** These activities were completed in guided virtual or cloud lab environments. They demonstrate tools and tasks I have practiced and are not presented as professional IT employment.

## Skills Demonstrated

| Area | Practical work completed |
| --- | --- |
| Windows support | Clean Windows 10 installation, initial configuration, user permissions, administrative tools, and Local Group Policy |
| Troubleshooting | Event Viewer, Windows Network Diagnostics, ping, Resource Monitor, and Windows Memory Diagnostic |
| Remote support | Remote Desktop configuration and remote access to a Windows system |
| Networking | Connectivity troubleshooting and introductory Nmap analysis of devices, ports, and services |
| Data protection | File History, system backup, and recovery-related tools |
| Automation | A basic Windows PowerShell script completed in a guided lab |

## Lab Highlights

### 1. Windows 10 Installation and Initial Configuration

**Objective:** Practice installing and preparing a Windows workstation for use.

**Work completed:**

- Performed a clean Windows 10 installation in a guided lab environment
- Completed initial operating-system configuration
- Practiced working with Windows settings and administrative tools

**Help-desk relevance:** Reinforced the steps involved in preparing a workstation, recognizing common setup requirements, and documenting configuration work.

### 2. Windows and Connectivity Troubleshooting

**Objective:** Diagnose simulated user and network-connectivity problems with a structured troubleshooting process.

**Tools practiced:**

- Event Viewer
- Windows Network Diagnostics
- ping
- Resource Monitor

**Help-desk relevance:** Built familiarity with gathering symptoms, checking system information, testing connectivity, narrowing likely causes, and communicating findings clearly.

### 3. Remote Desktop Support

**Objective:** Configure remote access and connect to a Windows system in a controlled lab.

**Work completed:**

- Configured Remote Desktop access
- Practiced remotely accessing a Windows system
- Reviewed the role of permissions and connectivity in remote support

**Help-desk relevance:** Provided introductory experience with the type of remote-access workflow commonly used to assist users who are not physically present.

### 4. Windows Administration and Data Protection

**Objective:** Practice common workstation-administration and recovery-related tasks.

**Work completed:**

- Configured printers and external devices in network and Windows-domain lab environments
- Worked with user permissions and Local Group Policy
- Used Task Scheduler and Windows Memory Diagnostic
- Practiced File History and system-backup tasks

**Help-desk relevance:** Strengthened familiarity with the Windows tools used to support users, maintain workstations, and protect or recover user data.

### 5. Introductory Network Analysis with Nmap

**Objective:** Build foundational awareness of devices and services visible on a network.

**Work completed:**

- Used Nmap in a guided lab
- Identified network devices, open ports, and available services
- Practiced interpreting introductory scan results

**Help-desk relevance:** Improved understanding of how network visibility and service availability can support connectivity and access troubleshooting.

### 6. Basic PowerShell Automation

**Objective:** Gain introductory experience using PowerShell to automate a Windows task.

**Work completed:**

- Created a basic Windows PowerShell script in a guided lab
- Practiced the relationship between commands, scripts, and repeatable support tasks

**Current level:** Foundational. I am continuing to build PowerShell knowledge and do not present this as advanced scripting experience.
